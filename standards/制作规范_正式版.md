## 零、反同质化铁律（最高优先级）

> 本铁律优先于本规范其余所有条款；与任何章节冲突时，以本节为准。

### 0.1 节奏 ≠ 情节

- 节奏是节拍骨架：第几张该发生什么。S1-S8（情感因果链）、Z1-Z8（视觉扩张链）是全账号统一的节拍，不随单篇变化。
- 情节是骨架上长什么肉：每个节拍上具体发生什么。情节必须逐篇差异化。
- 同质化的根因，是把节奏当成了情节模板，导致每篇都填成「长辈心结 + 材质复制 + 安全绳救援 + 认错 + 跟回家」。

### 0.2 四把锁（反换皮）

每篇新作在选题阶段必须与本系列已发布作品逐把对照以下四把锁，且至少 2 把不同：

| 锁 | 高发换皮形态（已出现） | 差异化的反例 |
|---|---|---|
| 越界者 | 长辈越界，主角旁观并救援 | 主角本人主动越界 |
| 关系人物 | 背负心结的长辈（父亲/导师/哥哥） | 同龄挚友、陌生人、对手，或无固定关系人物 |
| 母题逻辑 | 环境记录/复制/替换进入者 | 寄存、交换、索债、诱捕、预言、交易 |
| 闭环方式 | 安全绳救援 + 认错 + 异常跟回家 | 代价偿还、身份反转、主动选择、交易完成 |

### 0.3 一票否决

四把锁中 ≥3 把与同系列已发布作品相同，判定为「换皮」，选题阶段直接打回，不得进入分镜。

### 0.4 选题阶段强制自查

新篇选题卡必须逐项回答，任一项仍指向「与上一篇相同」，即回到 0.2 重新设计：

1. 本片的越界者，与本系列上一篇是同一类型吗？
2. 关系人物仍是「背负心结的长辈」吗？
3. 母题逻辑仍是「环境记录/复制/替换人」吗？
4. 结尾仍是「救援 + 认错 + 异常跟回家」吗？

（反面案例：K1 水库泥人、K4 溶洞脚印、K2 冰川冰体三篇共享上述四把锁，属典型换皮；K2 重构版以「主角主动越界 + 同龄挚友 + 寄存还债 + 身份反转」四把全换。）

### 0.5 共享风格 ≠ 共享情节

- 共享风格锚点只允许复用拍摄行为、现场光线、生活材质、设备缺陷和非电影化边界。
- 禁止复制来源篇人物、具体地点、代表道具、异常机制、字幕或关键构图。
- 风格一致性不能豁免“四把锁”；统一的是记录现实的方式，不是故事发生的方式。

### 0.6 最近5篇账号级同质化（V2.8）

> 四把锁继续负责“同系列内部反换皮”；本节新增“整个账号最近发布序列反重复”。两者必须同时通过。

每篇新作在选题阶段必须与账号最近发布的 **5 篇作品**逐篇比较；已有明确排期的待发布作品也应纳入最近序列。比较不看“道具名称是否不同”，而看用户实际消费到的机制：

| 维度 | 权重 |
|---|---:|
| 核心异常机制 | 25 |
| 故事发动机 | 15 |
| 主角进入方式 | 10 |
| 核心异常载体 | 10 |
| 主要视觉空间 | 10 |
| 中段升级方式 | 10 |
| 高潮形式 | 10 |
| 人物关系 | 5 |
| 现实残留 / 闭环 | 5 |

- 0–39：低风险；
- 40–54：轻度重复，检查是否只是合理系列识别度；
- 55–69：中高风险，必须改变至少 2 个高权重维度；
- ≥70：高风险，原则上选题退回。

**机制换皮一票否决：** 即使总分未达到70，只要“核心异常机制 + 中段升级逻辑 + 高潮兑现方式”三者同时与近期作品相同，直接退回；不得以年代、地点、道具或人物性别不同作为放行理由。

账号级生产原则：**品牌连续，机制跳跃。**

详细执行见 `抖音推流评分与发布后漏斗规范_V1.4.md`。

## 一、核心公式

**鼠鼠传播机制（样本观察）：** 普通人的现实处境 + 一个能改变生活的愿望/任务 + 关系人物带路 + 空间逐层进入 + 规则或禁忌出现 + 异常变成现场事件 + 悬念余波。

**冷启动适配公式：** 标题/封面先泄露强异常 + 1~3张建立普通人动机 + 关系人物带路 + 主角触发规则 + 异常直接反击现实 + 现实任务与人物关系闭环 + 异常原因留白。

**我们的差异化：** 提炼鼠鼠的日常代入、关系引路与现场升级效率，压缩其样本中的长铺垫；再加入系列专属视觉母题、现实锚点与轻量世界观。

### 1.1 选题准入（先选题，后写分镜）

每篇必须同时通过以下四项：

1. **地点有陌生感：** 真实或让人听过的地域/职业场景（深山道班、旧厂房、海岛、返乡村落等）；不能只写抽象"某个诡异地方"。
2. **动机够日常且够痛：** 旅行、求职、考研失利散心、返乡、替人送东西、参加集体活动等——主角为什么在场，第一张就能说清。同时必须有一个一句话能让人共情的情绪锚点（失去、迷茫、愧疚、孤独），对标鼠鼠"考研失败散心"的瞬间代入力。
3. **异常够具体：** 必须能被单张画面一眼识别（墙里的腿、窗外巨脸、重复出现的人、会移动的考勤名字等）；不能只靠"感觉不对"。
4. **有可争论的真相：** 结尾至少留下两个彼此竞争的解释，而不是把设定全部讲完。

### 1.2 单篇传播闭环

每篇先确定节奏模式，再按以下顺序写出一句话答案：

`节奏模式 → 我是谁 → 我为什么来（含情绪锚点）→ 谁/什么让我进入 → 我直接看见什么异常 → 鼠鼠：规则如何被触发 / Zayn：母题如何同源复现 → 异常怎样作用于人物与现实 → 此次任务/事件如何结束 → 鼠鼠：人物关系如何结束 / Zayn：终局如何重读前文 → 威胁或未知是否仍在生效`

任何一项答不出来，先补故事，不进入生图。

闭环必须同时满足：

1. **任务/事件闭环：** 收网、送达、返乡、调查、逃生、仪式或接受等开篇目标必须得到明确结果，不能在异常出现后被遗忘。
2. **所选节奏闭环：** 鼠鼠或混合模式必须落地带路人的亏欠、告别、误解或选择；Zayn 模式必须让人物的进入、观察与最终行动形成结果。
3. **异常余波或终局重读：** 鼠鼠模式用现实残留证明异常仍在；Zayn 模式用最后一张改变前文含义。两者都不能用“未完待续”代替结局。

冷启动阶段禁止把关键因果、人物结局或现实任务留到下一篇。可以做同题材新故事，不以强制追更补全本篇。

### 1.2B 叙事形态：单篇完结与连续剧分集

- **STANDALONE（默认）**：执行上方 1.2 的完整单篇任务/事件闭环；不得用“下一集揭晓”代替本篇结局。
- **SERIAL_EPISODE（连续剧分集）**：只有绑定的 Runtime Request 显式声明 `narrative_form=SERIAL_EPISODE`，或兼容旧请求中**作品标题明确包含“第N集”**，才进入此模式；不可凭主角没有逃脱、审核失败或 Agent 主观判断擅自升级。
- 分集仍必须在本集完成可核实的**状态变化闭环**：具体目标/局部事件、人物行动或被迫回应、异常引发的结果与代价、结尾对至少三个前文事实的重读。可以保留整部剧的逃生结果、幕后机制与最终命运作为跨集悬念；**仅发现新怪物、开门或预告下一集，不自动算本集闭环**。
- 对独立 Story Critic，继续强制因果一致、已铺垫的选择与后果、人物动机、删帧测试、传播核与真实 PASS 证据；用户锁定的分集不得仅因按单篇默认 20–25 张节奏或末尾未揭开整剧真相而被判失败，也不得因此忽略真实的重复帧和逻辑矛盾。
- `story.task_closed` 在分集模式只表示**本集状态变化闭环已审核成立**，并不代表整部剧完结。正式 `reviews.story=passed`、SHA 绑定与其他生产门禁始终不变；任何审核 FAIL 都不得直接改写为 PASS。
- `locked_story` 且 `allow_structure_rewrite=false` 的正式 Story Critic 已 FAIL 时，同一正式来源不得靠反复运行 Driver/模型“撞通过”。自动调用须停在需要用户决策；改故事或重开评审纪元必须通过独立的显式来源修订及审核权威，不能篡改旧证据。

### 1.2A V2.5 传播核 / SHAREABILITY LOCK

V2.5+ 新篇在进入 `STORYBOARD_LOCKED` 前必须通过：

> **人物主动动作 → 异常直接回应 → 可见后果 → 10 秒可转述**

机器证据：`meta/story-semantic-review.json#propagation_core`。

硬要求：

- 主角必须做普通人自然会做的主动动作，不能只是继续观察；
- 异常必须产生直接、可辨认回应；
- Trigger / Response / Payoff 必须在 Storyboard 中定位；
- 默认 Trigger 不晚于总图数 50%，更晚必须解释；
- `retellable_in_10s=true`；
- `visual_causality` 不得为 weak；
- Golden Episode 只学习结构，禁止复制地点 / 道具 / 动作 / 高潮表皮。

执行细则：`standards/传播核与动作回应链规范_V1.0.md`

机器门禁：`episodes/_system/propagation_core_gate.py`

### 1.3 标题抓力自评（选题阶段即完成）

写完标题后，用以下三项快速打分，总分低于 8.5 分返回重写：

| 维度 | 权重 | 满分标准 |
|---|---|---|
| 代入速度 | 3 | 第一句就知道"我是谁、我在哪、我怎么了"，不需脑补 |
| 异常具体度 | 3 | 异常能用 5 个字转述给别人且对方能想象画面 |
| 信息密度 | 4 | 三句话讲完动机+异常+触发后果/矛盾，没有一句是废话 |


### 1.4 V2.1 概念野心与无字传播门禁

真实性用于限制采集表现，不用于限制超自然事件规模、虚构地理、梦境空间、神秘遗址或异常世界观。

1. 概念不要克制，镜头必须真实。
2. Story Lock 前生成 8–12 个候选，至少 3 个 A4/A5。
3. finalist 必须先定义 Cover / Mid / Climax 三张传播图。
4. 无字测试必须同时通过停滑、升级可读、好奇缺口。
5. 最终 Concept Voltage ≥80。
6. 不得因为现实中不存在而主动缩小巨大异常、虚构遗址、梦境侵入或异空间。
7. Story Lock 负责自洽；Authenticity / Visual Lock 负责把大胆概念拍得像真的。

详细执行见 `选题野心与图像传播力规范_V1.0.md`。

## 二、图片技术规范

### 2.1 比例与尺寸

- **默认比例（未指定时）：** **4:5**
- **默认尺寸：** **1080×1350 px**
- **可选比例：** 9:16，对应 1080×1920 px；只有用户、正式分镜或 `release-manifest.json` 明确指定时采用
- **画幅锁定：** 一旦进入正式分镜，同篇正文不得无剧情理由混用画幅；历史已锁 9:16 的剧集不追溯改成 4:5
- **全链路同画幅：** `Frame Contract → Generation Request → RAW → Normalize → Approved → Release` 必须保持本集锁定比例；Normalize 默认禁止裁切，不能拿另一比例的生成结果靠裁图修成正文比例
- **无黑边、无白边、无留白；禁止用拉伸或模糊填充补比例**

详细执行见 [`生产引擎与画幅规范_V1.2.md`](生产引擎与画幅规范_V1.2.md)。

### 2.2 画风标准

通用基线是“现场采集的不完美”，不把“暗”本身当成恐怖：

- 曝光服从真实现场，不强制暗光；允许晴天、阴天、雨雾、黄昏、车内、室内和夜间；
- 采集缺陷必须有原因：低照产生噪点/慢快门，走路产生方向性手抖，屏幕翻拍产生摩尔纹/反光，雨雾产生对比下降；
- 构图允许倾斜、主体偏位、边缘切到物体和自然遮挡；
- 光线可以不均匀：过曝的窗、死黑角落、混合色温都允许，只要现场物理成立；
- **绝对不能：** 为恐怖统一压暗、无原因统一噪点、完美棚拍、强HDR、商业摄影、无剧情理由的概念海报感。

用户未显式指定其他视觉体系时，默认采用 M00“现实生活纪实母版”，并执行 [`风格锚点_MP4_网吧_流水席_旧数码_V1.2.md`](风格锚点_MP4_网吧_流水席_旧数码_V1.2.md)。M00 只锁定现实优先的视觉语言；年代和采集设备物理真实性优先，MP4、网吧、流水席、误入小镇只是校准来源。

### 2.3 第一人称视角与采集设备

- 默认采用第一人称消费级采集视角；主采集设备可以是手机、早期拍照手机、廉价数码相机或剧情明确成立的其他消费级设备。
- 全篇应持续让读者感到“拍摄者在场”。可通过手、脚、方向盘、倒影、屏幕翻拍、镜头高度、前景遮挡等建立在场感，不为凑比例强行露手。
- 当前第一视角设备不得无解释完整入镜。
- **不能出现：** 女主角无剧情必要的正面清晰面部、无解释的第三人称旁观视角。镜面、固定机位、他人接拍或第二采集源必须在分镜中写明物理来源。

### 2.3.1 导演镜头、光影与异常隐藏

新制作默认执行 [`导演镜头光影与异常隐藏规范_V1.0.md`](导演镜头光影与异常隐藏规范_V1.0.md)：

- 每集必须同时具有大场景（extreme_wide/wide）与小场景（close/detail），至少覆盖 3 种景别；同景别连续最多 2 张；
- 同一精确拍摄位置不得重复使用；同一地点允许回访，但摄影者必须移动到新机位并获得新信息；
- 允许参考经典电影长期积累的负空间、深景异常、框中框、遮挡揭露、反射第二信息层、明暗边界等**镜头结构**，但必须翻译成故事内真实摄影行为，禁止复刻具体电影镜头；
- 每帧光影必须来自可解释的现场光源，并说明其隐藏/揭露/引导功能；禁止无来源电影主光、轮廓光和为了悬疑凭空加雾；
- 悬疑、怪谈、民俗、旅行异常、旧物异常等题材至少安排一帧把异常有效藏在镜子、水面/湿地、玻璃反射、雾气、光影、屏幕反射、门窗、前景遮挡或剪影中；载体必须增加新信息并符合物理；
- 上述字段写入 `meta/shot-progression-review.json` schema_version=3，并进入 Resolved Frame Contract 与最终实际像素审核。

### 2.4 角色一致性

**Frame01 人物身份锚定规则：**

新篇首次生产时，如果存在明确核心人物：

第一帧必须优先承担“人物身份介绍”和“视觉身份建立”职责。

推荐形式：

- 自拍；
- 手机前置视角；
- 日常合影；
- 生活场景正脸照片。

目的：

Frame01 不作为普通剧情帧处理，而作为后续生产的人物视觉基准。

Frame01 进入：

```text
Character Identity Anchor
→ Character Contract
→ Visual Lock
→ Batch Production
```

例外：无明确人物主角、纯环境叙事、物件怪谈可以跳过。

**固定角色锁定规则（全系列通用）：**

- 每个系列的核心角色必须有参考图锁定，存放于该系列的 `assets/characters/` 目录
- 参考图要求：正面半身、环境光匹配该系列的现场光设定、分辨率不低于 512px
- 每次生图前将参考图作为角色锁定 prompt 注入
- 审核时逐张检查面容是否漂移

**每篇新角色锁定流程：**

- 第一张出现新角色时，必须额外生成 2-3 张该角色的特写/不同角度参考
- 从中选定一张作为该角色后续统一的锁定图
- 同一角色后续出图均以锁定图为基准

- **豁免：** 恐怖实体或只出现一次的功能性配角（如路人、一闪而过的窗外巨脸）可跳过特写锁定流程，避免破坏神秘感。但同一角色若跨篇重复出现，必须在第二次出现时补做锁定。

**第一视角主角规范：**

- 系列主角必须锁定：服装颜色+款式、发型颜色+长度、是否戴眼镜
- 第一视角只露手/脚/局部
- 不出现正面清晰面部
- 主角形象描述写入该系列的 episode doc

### 2.5 采集真实性与三图校准（沿用现有 episode 目录）

- 每篇选题卡或正式分镜必须在现有 `docs/` 文档中登记真实性方案：主采集设备、拍摄者、拍摄原因、锁定画幅的设备限制（未指定时默认4:5 / 1080×1350），以及稳定/受限/失控三种现场状态的成像结果。
- 当前第一视角设备不得无解释完整入镜；若设备、拍摄者或第二采集源出现，必须在分镜中写明镜面、固定机位、接拍或其他物理成立原因。
- 正式网页 GPT 交接前，沿用现有 P0/四图视觉准入流程完成三张校准：普通相册基线、最差但剧情成立的拍摄条件、首次重大异常。三张是正式分镜内的检查点，不增加默认 20 张或最多 25 张发布图数量；通过后优先复用为对应成片图。
- 校准结果、日期及批准的分镜/版本哈希写入现有验收或交接文档。未实际查看或未记录的校准不得作为通过依据。
- 逐图检查机位物理、计划外拍摄源、采集配置连续性和非电影化漂移；任一失败列为“必须重出”。每图最多一次内容返修，第二次仍失败则不通过并保留原图与返修记录。

普通相册四问、七项摄影红旗、剧情预登记豁免、结构化逐图审查及缺陷因果判断见 [`真实性与共享风格锚点规范_V1.1.md`](真实性与共享风格锚点规范_V1.1.md)。本节仍是三图校准与返修上限的唯一权威来源。



### 2.4 V2.1 环境物理与异常放大

- Weather 是物理条件，不是滤镜。
- 环境统一写入 `story-gates.visual.environment_contract`，使用 baseline / segments / frame_overrides。
- 高温、雨、雾、雪、风、沙尘等只表现有物理因果的像素结果。
- 每帧必须声明 narrative_role / frame_mode / impact_level。
- `anomaly_amplified` 与 `climax_impact` 为 impact 3–4，必须有现实尺度参照和 escalation_from。
- 异常可以远超现实尺度；真实性限制拍摄、光线、空气、材质、遮挡和人物行为，不限制异常本身。
- 详细执行见 `环境物理与异常放大规范_V1.0.md`。

### 2.5 V2.1 Resolved Frame Contract

正式 Visual Lock 校准与 Batch 前，每帧必须由机器编译唯一 Resolved Frame Contract，并产生 `frame_contract_sha256`。

- Story SHA；

### 2.6 V2.1 四层 Visual Lock 与有界并发

Visual Lock 使用四个实际像素角色：

1. ordinary_baseline
2. worst_capture_condition
3. first_major_anomaly
4. high_impact_admission

前三类保证“真”，第四类专门验证“异常敢放大以后仍然真”。不得因为异常巨大、超现实或不存在就主动压小；也不得用电影海报式光效/构图来伪造冲击力。

正式图片生成默认使用有界并发调度：

- 最大 worker = 3；
- Ledger 单写者；
- 独立 worker temp/output/log；
- 高风险 / 长关键路径优先；
- `escalation_from` 进入依赖；
- 技术失败 Fail-soft；
- 429/timeout/5xx 自适应降速；
- 内容返修仍保持每帧普通返修最多一次。

Fast Frame Scout 不在本阶段，Final Frame Semantic Critic 不得删除。

### 2.7 V2.1 Fast Scout 与 Final Candidate Snapshot

Fast Scout 只做高风险提前拦截，不是 Production PASS 权威。低风险帧默认不额外增加模型调用；高风险帧若发现 identity/prop/weather/scale/POV 等明显错误，可提前进入返修。Scout 不确定或技术失败时必须交给最终 Critic。

V2.1 Delivery Adapter 不允许重新扫描 mutable publish 目录组装“最新版本”；必须消费 verified Snapshot。

### 2.8 V2.1 系统闭环：Migration / Regression / Publish Data Review

- 历史 Episode 不追溯补造 V2.1 PASS evidence；Migration 默认只读。

## 三、异常可读性与实体类异常规范

### 3.1 异常必须可读

异常不要求必须是“实体”。行为、路线、时间、影像、物件、空间、名单、屏幕或实体都可以承担核心异常。

- 手机端必须能辨认“哪里不对”，但不要求第一次就解释原因；
- 不能靠把画面压暗来隐藏信息；
- 关键证据宁可局部、不完整，也不能糊到无法验证；
- 记录型题材允许从屏幕/档案开始，但后续必须出现现实层交叉验证或物理后果。

### 3.2 实体类异常（仅当本篇存在实体时）

- 实体范围不限制：超自然实体、类人实体、巨型生物、不可名状之物均可；
- 不追求数量，追求与主题强关联；
- 实体出现必须符合现场光与采集设备，不为实体额外开“电影灯”；
- 不能用青面獠牙、贴脸鬼或完整展示替代异常设计。

### 3.3 实体递进（条件规则）

只有本篇确实存在实体时才执行。可以按：

`痕迹 → 局部 → 可辨认轮廓/全貌（若剧情需要） → 现实影响`

递进，但**不强制每篇必须给实体全貌**。如果故事的核心是影像、时间、路线、群体行为、空间错位或旧物证据，应按该异常自身证据链递进。

同一级别不得连续重复超过2张；每次再次出现必须新增距离、清晰度、规模、规则、人物压力或现实影响中的至少一项。

## 四、视觉母题方法论

> 视觉母题是系列辨识符号。每个系列定义 1-2 个核心母题，写入该系列的 episode doc。以下为定义母题的规范，不限定具体母题内容。

### 4.1 母题定义规范

每个系列在 episode doc 中定义核心视觉母题时，必须覆盖：

1. **母题名称与视觉特征：** 清晰的视觉描述，生成 prompt 可直接引用
2. **剧情承载规则：** 母题不是装饰，至少在一处关键节点（异常初现/证据推翻/终局威胁）承担剧情信息
3. **出场频率控制：** 不强制每张出现，避免视觉重复和设定硬塞
4. **第一视角接入方式：** 主角如何与该母题互动（手扶、玻璃反光、画外遮挡等）

### 4.2 辅助场景

每个系列可定义 1-2 个辅助场景，同样写入 episode doc：
- 场景建筑/环境特征
- 内部关键道具清单
- 时代锚点（具体年代+视觉特征）

## 五、字幕规范

### 5.1 全系列锁定视觉规范

所有系列今后新制作或重制的字幕，统一执行 [`最终字幕视觉规范_V1.2.md`](最终字幕视觉规范_V1.2.md)。该文件是字幕视觉参数、排版和发布前字幕验收的唯一来源，替代此前所有“28px + 半透明黑色圆角气泡 + 居中/左中气泡”的历史样式。

- 锁定参数：画布跟随当集 manifest；4:5=1080×1350（未指定默认），9:16=1080×1920；Microsoft YaHei Bold 42px/700、纯白字、4px 黑描边、黑色 50% 轻阴影、无背景气泡、左对齐、左右安全边距 72px、最多两行。
- 默认字幕位于**左侧中部安全区**：Y≈画面高度 42%–62%，canonical 默认约 52%；逐张先检查人物脸、异常主体、手部动作、关键道具、地址/原生文字和因果线索，只有左中被占用时才允许移出该区域，并记录具体避让原因。最终发布语义审核必须查看实际带字幕像素，任何遮挡关键证据直接 FAIL。
- 这是“以后”制作的统一基线，不要求追溯重制既有已验收或已发布成片。

### 5.2 内容与静音可读

- 每图以一条第一人称、口语化即时记录为主；推荐 12–22 字，原则上不超过约 28 字，关键转折最多两行。
- 每句只承担一个功能：交代动机、抛出异常、给出证据、推翻解释、升级威胁、即时判断或留下余波；不写小说式说明文，也不解释完整超自然机制。
- 因果、物证、同源逻辑优先由画面完成。终局可使用回扣当集母题的短金句，避免重复画面内已可见的文字。
- Zayn/混合模式可安排 2–4 张无字幕关键图；正式分镜必须标明，且删掉字幕后仍能读懂异常直见与物证链。

### 5.3 系列叙事语气

各系列可以保留差异化文案语气，例如古籍志怪采用更短的情绪 OS、使用语气词或终局玩梗；但这些差异只影响文案节奏，不能改变 5.1 的视觉参数、最多两行限制和剧情证据避让要求。

### 5.4 字幕人话化与声音连续

正式字幕除视觉规范外，执行 [`字幕人话化与声音卡规范_V1.1.md`](字幕人话化与声音卡规范_V1.1.md) 的声音卡、连续三图、朗读、删字幕和线索后果测试。该细则只管理内容表达，不改变 5.1 的视觉参数。

## 六、叙事结构

### 6.1 鼠鼠节奏定义与标注

#### 鼠鼠原版样本节奏（仅作观察）

下载样本呈现出以下稳定推进方式：

`普通人生活 → 个人愿望/现实困境 → 关系人物带路 → 空间逐层进入 → 规则或禁忌 → 异常现场爆发 → 悬念余波/追更`

样本允许用较多画面建立生活、关系和新地点，甚至采用约30张及“未完待续”。这不是本账号冷启动阶段的默认篇幅，也不能据此推断鼠鼠所有作品都采用同一节奏。

#### 鼠鼠节奏·冷启动适配版（选择鼠鼠或混合模式时强制执行）

选择鼠鼠或混合模式的作品，其选题卡、故事大纲和分镜文档必须标注以下节奏标签；同一标签可覆盖多张，但八项不得缺失：

| 标签 | 名称 | 必须回答的问题 |
|---|---|---|
| `鼠鼠节奏-S1` | 日常代入 | 主角是谁，正面临什么普通但具体的现实任务？ |
| `鼠鼠节奏-S2` | 关系引路 | 谁把主角带到异常现场，他与主角有什么未完成的关系？ |
| `鼠鼠节奏-S3` | 异常证据直见 | 读者在画面中直接识别了什么一眼能懂的异常证据？记录型题材可由屏幕、旧录像、档案或照片承载首个证据。 |
| `鼠鼠节奏-S4` | 规则建立 | 哪个动作不能做，或带路人用什么异常行为提醒危险？ |
| `鼠鼠节奏-S5` | 越界触发 | 主角为何主动或被迫触发规则？ |
| `鼠鼠节奏-S6` | 可见对抗 | 异常如何直接影响船、门、绳索、人物或空间？ |
| `鼠鼠节奏-S7` | 人情闭环 | 开篇任务与人物秘密分别怎样结束？ |
| `鼠鼠节奏-S8` | 异常余波 | 哪个现实残留证明异常仍在，但不要求下一篇补完？ |

分镜文档的每个 Act 标题后至少标注一个对应标签；关键转折图在“功能”栏再次标注，例如：`功能：鼠鼠节奏-S5 越界触发`。

**《舟山·水下的船》标注示例：**

`S1 帮舅舅收最后一网 → S2 舅舅带路并隐瞒父辈旧事 → S3 直接看见水下同船 → S4 舅舅要求不要照水下的人 → S5 主角开灯 → S6 水下船上升并拉扯渔网 → S7 收网/卖船完成且舅舅说出亏欠 → S8 割断的网返回，水下甲板多出第二个人`

### 6.2 节拍分配（默认20张，最多25张）

> 该上限用于 v2.2 后的新作品；已发布或已完成作品不倒推返工。

| 阶段 | 建议张数 | 鼠鼠节奏标签 | 功能 |
|------|:--:|------|------|
| Act1 日常裂缝 | 1-3 | S1 + S3 | 1张交代现实任务；标题/封面先泄露异常；最迟第3张让读者直接识别异常证据；记录型题材可由屏幕、旧录像、档案或照片承载 |
| Act2 关系引路 | 4-7 | S2 + S4 | 带路人把主角留在现场，并通过一句话或一个反常动作建立规则 |
| Act3 越界触发 | 8-11 | S5 | 主角因现实目标而触发规则；异常必须立即做出可见回应 |
| Act4 可见对抗 | 12-16 | S6 | 异常持续影响现实，核心异常的主要表现、规则或现实影响最迟在本段清晰成立；若存在实体则保持可辨认和连续；主角做出不可逆选择 |
| Act5 人情闭环 | 17-20 | S7 | 完成开篇现实任务，揭开人物隐瞒的旧事或选择，但不解释超自然机制 |
| Act6 异常余波 | 21-25（可选） | S8 | 用返回的物件、新照片、异常来电或新目击完成余波；不得重新开启一条必须追更才能结束的主线 |

20张已经完成 S1~S8 时直接结束，不为凑满25张增加档案、赶路或重复惊吓。

### 6.3 关键规则

- **标题/封面先给异常，正文快速补日常。** 前3张必须同时完成现实动机和异常证据直见；记录型题材的“直见”可以发生在屏幕、旧录像、档案或照片中，但证据必须具体可辨；不得连续超过2张只铺环境、人物履历或世界观。
- **异常优先形成可见证据。** 非记录型题材优先由人物、环境、物件或空间直接呈现异常；记录型题材允许屏幕、旧录像、档案、照片等作为首次异常载体，但后续必须由现实物证、人物行为、路线、空间或物理后果完成交叉验证，不得从头到尾只在记录中自证。
- **每3~4张必须发生一次信息变化：** 新地点、关系变化、规则出现、规则触发、现实受影响、人物秘密、异常余波七选一；禁止连续多张只换角度。
- **规则必须被触发并产生后果。** 不能只说“不要回头/不要开灯”，随后规则与剧情无关；主角触发规则必须来自现实目标、情感冲动或被迫选择。
- **带路人负责关系，不负责讲完设定。** 他可以知道旧事、禁忌或自己的亏欠，但不应准确解释异常来源、运行原理和全部历史。
- **中段稳步升级，不跳级。** 每次异常重现必须增加距离、清晰度、规模、主动性或现实影响中的至少一项。
- **核心异常不得拖到结尾才首次成立。** 最迟 Act4 应让读者清楚理解异常的主要表现、规则或现实影响；若本篇存在实体，应在剧情需要的位置形成可辨认形态，但不强制给出实体全貌；终局应提高威胁、改变关系或重读前文，而不是重复第一次亮相。
- **人物先闭环，原因可留白。** 现实任务和人物秘密必须有结果；异常为何出现、究竟是什么可以无人知道。
- **三个终局连击收尾：** 现实任务结果 → 人情秘密/选择 → 异常余波。
- **冷启动阶段禁用“未完待续”代替结局。** 同世界观下一篇必须是新的自治故事；上一页留下的核心冲突不得要求下一篇补完。
- **结尾必须双层留白。** 事实层留一个时间/人物/物品矛盾，解释层保留至少两种成立可能；不在字幕中直接提问。

## 六-A、Zayn节奏（独立章节）

> 本章与“鼠鼠节奏”并列，不覆盖 S1~S8。每篇在选题卡先写明：`节奏模式：鼠鼠 / Zayn / 混合`。鼠鼠适合现实关系与规则对抗；Zayn 适合探索、异变、未知生态和世界尺度翻转；混合模式用鼠鼠完成人物行动，用 Zayn 完成视觉规律与终局扩张。

### 6A.1 三篇样本呈现出的稳定方法

1. **画面先于解释：** 主要信息由物体、身体、空间变化传递，不靠日志、术语或旁白把异常讲明白。
2. **一篇只养一个异常母题：** 面具、透明膜、粉色菌丝等只是样本中的载体；真正可复用的是让同一种形态、材质、颜色或运动规律跨物体复现。
3. **重复不是复制：** 母题每次再出现都换载体并增加含义，从“一个东西不对”推进到“整套系统遵守同一规律”。
4. **人物从观察者变成参与者：** 前段可以目击，中段必须接触、跟随、逃离、破坏、接受或被改变，不能全篇站着看奇观。
5. **尺度不断外扩：** 手持物/局部生物 → 人体/舱室/物种 → 建筑/生态/地貌，终局用更大尺度重新解释前文。
6. **事件闭合，原因留白：** 人物此次进入、调查、逃生或仪式必须有结果；异常来源可以没有人知道。

| 样本 | 画面推进链 | 终局作用 |
|---|---|---|
| 《海渊371》 | 潜艇工作现场 → 异常物件 → 舱内系统与物理状态失常 → 海底建筑 | 把一次舱内事故重读为人物正在接近更大结构 |
| 《神秘岛》 | 登岛 → 单体异常生物 → 同源特征跨物种复现 → 异常生态群落 | 把“岛上有怪物”重读为“整座岛属于同一生命结构” |
| 《尤阁寨的羽化》 | 外来者进村 → 面具/粉色生长物 → 身体与群体仪式同源变化 → 全村结果 | 把“村民遭遇异常”重读为他们主动完成并接受一次集体转化 |

### 6A.2 Zayn节奏定义与标注

选择 Zayn 或混合模式时，必须在大纲和分镜中标注以下八项：

| 标签 | 名称 | 必须回答的问题 |
|---|---|---|
| `Zayn节奏-Z1` | 可信进入 | 人物通过什么具体职业、旅程、任务或地方行为进入现场？ |
| `Zayn节奏-Z2` | 母题证据直见 | 前3张在画面中直接识别哪个一眼能认出的异常母题或异常证据？记录型题材可由记录载体承载首证据。 |
| `Zayn节奏-Z3` | 同源复现 | 同一视觉规律怎样出现在第二种载体上？ |
| `Zayn节奏-Z4` | 规律确认 | 第三次复现增加了什么信息，使它从偶发怪物变成系统规律？ |
| `Zayn节奏-Z5` | 人物卷入 | 人物做了什么不可撤回的动作，或身体、工具、退路怎样被影响？ |
| `Zayn节奏-Z6` | 尺度扩张 | 异常怎样从局部扩展到舱室、群体、生态、建筑或地貌？ |
| `Zayn节奏-Z7` | 事件闭合 | 此次进入、调查、逃生、献祭或接受最终得到什么明确结果？ |
| `Zayn节奏-Z8` | 终局重读 | 最后一张怎样改变至少两张前图的含义，同时不解释异常来源？ |

同一标签可覆盖多张，但 Z1~Z8 不得缺失。混合模式必须分别标注 S1~S8 与 Z1~Z8，不能用同一句空泛说明同时代替两套因果。

### 6A.3 节拍分配（默认20张，最多25张）

| 阶段 | 建议张数 | Zayn节奏标签 | 功能 |
|---|:--:|---|---|
| Act1 可信裂缝 | 1-3 | Z1 + Z2 | 用具体人物行动建立现场，最迟第3张直接亮出核心母题；禁止先讲长背景 |
| Act2 同源复现 | 4-7 | Z3 | 母题进入第二种载体，画面仍可被误解，但不能只是换角度重复 |
| Act3 规律确认 | 8-12 | Z4 | 第三种载体出现，确认异常有稳定形态或行为规律，并推翻普通解释 |
| Act4 人物卷入 | 13-17 | Z5 | 异常影响身体、工具、退路或选择，人物必须采取不可撤回的行动 |
| Act5 尺度扩张 | 18-21 | Z6 | 从单体上升到群体、系统、生态、建筑或地貌，形成一次明确尺度跃迁 |
| Act6 闭合重读 | 22-25 | Z7 + Z8 | 给出人物/事件结果，再用终局画面重释至少两处前文线索；不解释根因 |

20张已经完成 Z1~Z8 时直接结束。不得为了等“大场面”而在前半连续陈列环境、器材、档案或不同怪物。

### 6A.4 异常母题扩散规则

每篇 Zayn 或混合模式作品，必须先在 episode doc 写一行：

`异常母题 = [核心形态] + [材质/颜色] + [运动或生长规律]`

并满足：

1. **至少三个不同载体：** 例如物件 → 人体 → 地貌，或单体生物 → 多物种 → 整体生态；同一物件换三个角度不算三个载体。
2. **至少三级尺度：** 细节/手持物、人物/房间/单体、群体/建筑/环境各出现一次。
3. **每次复现新增推论：** 第二次证明可传播或同源，第三次证明范围或目的；只增加体积和数量不算有效升级。
4. **视觉先完成信息：** 字幕只写人物行动、即时判断或现实后果，不替画面命名原理，不出现“这是一种会感染全岛的某某物质”式讲解。
5. **允许战略性静默：** Zayn 或混合模式全篇可安排2~4张无字幕关键图，但相邻画面必须让读者读懂人物为何来到这里、下一步为何发生。

### 6A.5 终局重读与闭环验收

发布前逐项回答，任一项为“否”则返回大纲：

- 第3张前是否已经在画面中直接识别核心异常证据？非记录型题材不得只看仪表、日志或人物表情；记录型题材可由屏幕、旧录像、档案或照片起手，但后续必须完成现实层交叉验证。
- 同一母题是否在至少三个不同载体上复现，并且每次增加新含义？
- 人物是否从观察转为行动，且这个动作改变了结果？
- 人物此次任务或事件是否已经结束，而不是用未知原因代替未写结局？
- 最后一张是否让读者重读至少两张前图？删掉最后一张后理解完全不变，视为终局失败。
- 结尾是否只确认“发生了什么/人物去了哪里”，仍没有权威人物讲明“它为什么存在”？

### 6A.6 两套节奏的选择边界

| 维度 | 鼠鼠节奏 | Zayn节奏 |
|---|---|---|
| 主要驱动力 | 现实任务、人物关系、禁忌触发 | 异常母题、同源复现、尺度扩张 |
| 人物功能 | 带路、隐瞒、选择、情感闭环 | 进入、观察、接触、被卷入或接受 |
| 中段升级 | 规则被触发后直接对抗现实 | 同一规律跨载体扩散并改变环境 |
| 高潮 | 主角作出不可逆选择 | 局部异常显露为更大的系统或世界结构 |
| 结尾 | 人情结果 + 异常余波 | 事件结果 + 终局重读 |

### 6A.7 Zayn标题钩子

Zayn 模式仍然禁止学术式开场。标题用三句完成“可信进入 + 母题直见 + 同源矛盾”：

```text
句1：我因什么具体任务进入什么地方
句2：我直接看见了什么核心异常母题
句3：哪个不同载体出现了同一特征，并造成什么可见后果
```

模板：`我因[具体任务]进入[地点]。我直接看见[核心异常]。后来，[第二载体]也出现同一特征，而[人物/环境]开始发生[可见后果]。`

第三句只能扩大矛盾，不能直接宣布异常的名称、来源、目的或科学原理。

禁止照搬样本中的青铜面具、眼状岛屿、粉色肉质生长物、具体人物造型或连续镜头。只提炼“同源复现、尺度扩张、终局重读”的组织方法，所有实体、母题与事件必须原创。

### 6-B 混合模式执行法

> 混合模式不是第三套独立节奏，而是用鼠鼠节奏推动人物行动，用 Zayn 节奏组织异常母题的复现、扩张与终局重读。适用于既需要现实关系代入，又需要形成视觉系统升级的作品。

#### 6B.1 核心分工

| 叙事职责 | 采用的节奏 | 必须完成的内容 |
|---|---|---|
| 进入与行动 | 鼠鼠 S1-S5 | 现实任务、情绪锚点、关系引路、异常直见、规则建立与越界触发 |
| 异常升级 | Zayn Z3-Z6 | 同一母题跨至少三个载体复现，逐步从局部扩展到人物、空间、群体或环境 |
| 对抗与选择 | 鼠鼠 S6-S7 | 异常直接作用于现实，主角或关系人物作出不可逆选择，任务与人物关系得到结果 |
| 余波与重读 | 鼠鼠 S8 + Zayn Z7-Z8 | 现实残留证明异常仍在；事件闭合；最后一张改变至少两张前图的含义 |

混合模式的主线应遵循：

`现实任务进入 → 关系人物带路 → 异常母题直见 → 规则或规律触发 → 母题跨载体升级 → 异常作用于人物与现实 → 人物作出选择并完成任务 → 现实余波与终局重读`

#### 6B.2 默认节拍

| 阶段 | 建议张数 | 鼠鼠标签 | Zayn标签 | 执行要求 |
|---|:--:|---|---|---|
| Act1 现实裂缝 | 1-3 | S1 + S3 | Z1 + Z2 | 第1张交代现实任务或情绪锚点；第3张前直接识别可辨认异常证据；记录型题材可由记录载体承担首证据 |
| Act2 关系与规则 | 4-7 | S2 + S4 | Z3 | 关系人物建立规则；异常在第二种载体上复现，不得只换角度重复 |
| Act3 越界与规律确认 | 8-11 | S5 | Z4 | 主角因任务、情感或被迫选择越界；第三种载体确认异常具有稳定规律 |
| Act4 可见对抗与卷入 | 12-16 | S6 | Z5 + Z6 | 异常直接影响人物、工具、退路或空间，并完成一次尺度跃迁 |
| Act5 人情闭环 | 17-19 | S7 | Z7 | 关系人物完成告别、亏欠、误解或选择；现实任务得到明确结果 |
| Act6 余波重读 | 20（可选至25） | S8 | Z8 | 用返回物件、新目击或现实残留证明异常仍在；终局重读前文，不解释根因 |

默认 20 张已经完成两套标签时直接结束，最多扩展至 25 张。扩展只能增加新的因果、人物选择或终局信息，不得增加赶路、档案、环境陈列或重复惊吓。

#### 6B.3 强制标注与验收

每篇混合模式作品的选题卡、大纲和分镜开头必须写明：

`节奏模式：混合模式（鼠鼠主行动 + Zayn视觉扩张）`

并分别列出 `鼠鼠节奏-S1~S8` 与 `Zayn节奏-Z1~Z8` 的具体落点。每个 Act 标题至少标注一套对应标签，关键转折图在“功能”栏再次标注；不能用“兼具鼠鼠和 Zayn 风格”一句话代替双套标签。

发布前必须全部回答“是”：

- 第3张前已经同时具备现实任务/情绪锚点和可辨认异常证据；记录型题材允许该证据首先出现在屏幕、旧录像、档案或照片中；
- 关系人物的规则或隐瞒真正推动了越界，而不是只负责讲设定；
- 同一异常母题至少在三个不同载体上复现，每次复现都新增推论；
- 人物从观察转为行动，且行动改变了人物关系或事件结果；
- 现实任务、人物关系和此次进入事件均已闭合，不用“未完待续”代替结局；
- 结尾同时具备现实残留与终局重读，异常来源仍然可以留白；
- 全篇默认 20 张、最多 25 张，字幕和画面没有遮挡关键线索。

混合模式一票否决：缺少任意一套 S1-S8 或 Z1-Z8；非记录型题材的核心异常长期只存在于仪器、日志、档案或聊天记录中且没有现场/现实验证；记录型题材虽可由记录载体起手，但若后续没有现实物证、人物行为、路线、空间或物理后果交叉验证，同样否决；母题只有三个角度没有三个载体；人物关系没有结果；最后一张删除后不改变前文含义。

## 七、标题规范

### 7.1 鼠鼠三句式

```
句1：我是谁 + 我正在完成什么普通任务
句2：我直接看见了什么具体异常
句3：我做了什么或发生了什么，使异常开始影响现实
```

### 7.2 模板

```
我叫XX，XX岁，因为[日常理由/现实任务]来到XX。我直接看见了[具体异常]。当我[触发动作]后，[可见后果/现实矛盾]。
```

“我原以为……直到……”可作为备选推翻结构，但不是强制句式；若使用，最后仍需落到可见后果。非记录型题材不能只靠仪器读数或档案文字完成钩子；记录型题材允许由具体可见的屏幕、旧录像、档案或照片异常完成首钩子，但后续必须由现实层证据交叉验证。

### 7.3 字数

不超过70字，手机端3行以内显示完整；禁用"诡异、恐怖、惊人"等空泛形容词代替具体异常。

## 八、发布规范

### 8.0 媒介边界：只做图文，不引入视频生成

- **Story OS 的正式产品形态是 image-first 图文系统。** Canonical 发布产物仅包括封面图片、按顺序排列的正文 publish 图片、已渲染字幕/字幕源、发布文案与对应的 SHA-bound evidence。
- **正式生产链禁止引入视频生成或图片转视频。** Golden Path、Release Gate、`PUBLISH_READY`、Release Package 均不得包含或依赖视频生成模型、静态图片拼视频、MP4/MOV 等视频容器、FFmpeg/视频编码器或视频专属审核证据。
- **不得以“平台兼容、单文件交付、字幕烧录、方便预览”等理由自动派生视频。** 字幕必须直接渲染到最终发布图片；图文发布完成即视为媒体成品完成。
- 系统、Agent、Runtime、脚本和测试不得把视频作为图文 Episode 的隐式 fallback、默认 exporter、可选尾部步骤或发布前置条件。
- 若未来产品定位确需支持视频，必须先修改本核心规范、Runtime/Release Contract 与机器门禁，明确新的产品边界后再实现；禁止先在代码中引入，再反向修改规范追认。

### 8.1 标签策略

- 每篇5~8个，避免堆砌。
- 场景标签：1~2个（与该篇地域/场景直接相关）
- 类型标签：2~3个（#都市传说 #细思极恐 #中式恐怖）
- 内容标签：1~2个（#AI故事 #抖音图文）
- 活动标签：0~1个（#RunNOW；仅活动有效时使用）

### 8.2 声明

每篇标注：**作者声明：内容由AI生成**

### 8.3 BGM

- 优先选择抖音发布页当时可用、授权状态明确的曲库音源；发布前再次确认音源未下架、未限用。
- 风格以中式民俗恐怖、低频氛围、节奏缓慢为主。纸嫁衣原声/择天记-Malic仅作为风格参考，不作为永久指定曲目。
- 连续3篇不得机械使用同一首BGM；应按故事的地域、年代和情绪选择，避免账号听觉同质化。

### 8.4 数据验收

<!-- V1.2_PUSH_FUNNEL -->

发布后统一按 **L1停留 → L2深度消费 → L3消费后动作 → L4作者链** 四层漏斗记录，不再只用播放量/点赞判断作品。

1. **L1停留：** 优先记录划走率，以及后台若提供的曝光→进入正文、首屏停留。划走率只能作为首屏/前段代理，不能写成01→02留存或前三张到达率。
2. **L2深度消费：** 记录均浏览图、平均阅读深度占比，以及后台真实完读/末页到达/逐页留存（如有）。均浏览图÷总张数只叫平均阅读深度占比。
3. **L3消费后动作：** 记录点赞、评论、收藏、分享；怪谈故事必须单独定性评论是否围绕正文证据形成竞争解释。
4. **L4作者链：** 记录主页访问、吸粉、主页转粉、旧作带动与系列回访（能取得时）。评论与作者链不得再合并成一个发布后结论。

每篇发布时同步锁定最终平台标题、实际封面文件及SHA256、平台裁切、正文首图、作品ID/链接、准确发布时间。

**数据窗口：** 6h / 24h / 48h / 7d。错过独立窗口写“未采集”，当前总览不得倒填。

### 8.4.1 率值命名与分母

禁止再使用无分母说明的“点赞率/评论率/收藏率/分享率”。

**曝光口径（有曝光时优先）：**
- 曝光点赞转化率 = 点赞 ÷ 曝光
- 曝光评论转化率 = 评论 ÷ 曝光
- 曝光收藏转化率 = 收藏 ÷ 曝光
- 曝光分享转化率 = 分享 ÷ 曝光
- 主页访问曝光率 = 主页访问 ÷ 曝光
- 曝光吸粉转化率 = 吸粉 ÷ 曝光

**播放口径（观察形成播放后的消费者动作）：**
- 播放点赞率 = 点赞 ÷ 播放
- 播放评论率 = 评论 ÷ 播放
- 播放收藏率 = 收藏 ÷ 播放
- 播放分享率 = 分享 ÷ 播放
- 播放主页访问率 = 主页访问 ÷ 播放
- 播放吸粉率 = 吸粉 ÷ 播放

**作者链：**
- 主页转粉率 = 吸粉 ÷ 主页访问

不同分母不得混在同一排名比较；后台若提供官方定义率值，必须标注“后台官方字段”。

完读率、末页到达率、逐页留存只采用后台真实字段；未提供写“未提供证据”。

### 8.4.2 可比样本

每篇只与同账号、相近发布时间龄、相近张数、尽量同题材的最近 **5–10篇**比较：
- 优先取10篇；
- 不足10篇使用已有可比样本；
- 不足5篇只记录，不判趋势强弱。

S/A/B/C 仅是账号内部相对等级，不是平台流量池。

### 8.4.3 四层诊断

| 诊断 | 典型信号 | 下一篇先修 |
|---|---|---|
| 首屏失败 | L1弱且L2通常也弱 | 标题/封面/图01/前三张 |
| 封面强、承接弱 | L1不弱但L2弱 | 01–05兑现、06–10信息净增 |
| 阅读强、互动弱 | L1/L2强但L3弱 | 双解释、回看证据、可转述规则 |
| 互动有、作者链弱 | L3成立但L4弱 | 系列承诺、主页识别、固定母题 |
| 完整闭环 | 四层均高于近期可比样本 | 保留结构变量，只换原创情节 |

### 8.5 发布频率与持续性

- **发布频率：每周 2-3 篇。** 这是根据竞品更新节奏形成的冷启动执行假设，不表述为平台算法规则。若连续生产导致质量评分低于8.5，应优先降频保质。
- **时间选择：** 初始测试晚间 19:00-22:00；连续发布至少3篇后，再与其他时段的同类内容比较。不得仅凭单篇表现认定某时段优劣。
- **内容储备：** 冷启动前至少储备 3-5 篇完整内容（含图+文案），避免断更。
- **持续性与质量同时守门：** 竞品数据显示鼠鼠早期作品互动较低、后期起步互动更高，但只能说明相关性，不能证明由发布频率单独造成。保持稳定更新，同时执行发布前8.5分门槛。
- **阶段目标（冷启动）：** 3 个月内粉丝过 5 万。达到后进入成长阶段，频率可调整为每周 1-2 篇，单篇质量要求提高。
- **追踪指标：** 除单篇数据外，每月追踪赞粉比（对标鼠鼠 17:1）、篇均赞增长曲线、新发作品 24h 起步曝光。


## 九、世界观系统

### 9.1 核心原则

世界观定义写入各系列的 episode doc。以下为所有系列必须遵守的原则：

- **冷启动阶段（账号未形成稳定受众）：** 单篇必须自治，不要求读者补课；每篇只允许 1 个无需前作也能理解的暗线
- **成长阶段（已有稳定系列受众后）：** 用重复细节（特定道具、时间戳格式、同一连接者角色）建立跨篇连接；暗线必须奖励老读者，而非阻碍新读者
- **世界观上限：** 作为创作地图，不是每篇都要讲完的数字。避免在早期作品中做长段设定说明

### 9.2 跨篇连接机制

每个系列在 episode doc 中定义以下连接机制：

1. **连接者角色：** 一个跨篇出现的固定角色，每次出现只推进一个新信息，新读者不需要认识他也能理解当篇。老读者认出他是奖励。
2. **重复道具/符号：** 一个在系列中反复出现的物品或符号（如特定食物、特定格式的时间标记），出现时不解释，让连续观看的读者自行发现。
3. **连接强度控制：** 每篇的暗线连接不超过 1 个道具/符号 + 1 个连接者出场。禁止要求读者先看前作才能理解基本冲突。


### 9.3 自身标签进化

从模仿鼠鼠到建立自己的辨识度，按以下路径推进：

**第一阶段：结构学习期（0-3 个月，冷启动）**

- 提炼鼠鼠标题中的身份、动机、异常、推翻结构，并使用原创人物、事件与视觉表达
- 差异化抓手：比鼠鼠画面更稳定（角色锁定能力），比 Zayn 节奏更快
- 不做世界观说明，不要求读者补课

**第二阶段：辨识期（3-6 个月，5 万粉后）**

- 从已发布作品中提取 3 个被验证的独特元素（点赞和评论围绕哪些画面/设定集中），作为自身标签的种子
- 引入轻量跨篇连接（连接者角色 + 1 个重复符号），但不改变单篇自治原则
- 每 5 篇做一次自身标签复盘：哪些元素形成了读者期待？

**第三阶段：定型期（6 个月后，10 万粉以上）**

- 自身标签固化为账号简介和置顶作品的统一入口
- 可选择性引入 Zayn 式"伪档案/伪机构"世界观包装
- 内容方向可扩展到竞品未覆盖的细分领域（如特定地域系列、特定时代系列）
- 但始终保留鼠鼠的短平快传播公式为前提

**自身标签判断标准（每 5 篇复盘一次）：**

| 信号 | 含义 |
|---|---|
| 评论区反复提到某个元素/设定 | 该元素已形成记忆点，可强化 |
| 收藏/转发显著高于篇均 | 读者想"留着以后看"或"发给别人"，传播力好 |
| 连续 3 篇互动持平或下降 | 公式疲劳，需要新裂缝（场景/职业/异常类型） |

## 十、现实锚点与证据链模板

每篇必须包含至少3个现实锚点，其中至少1个是异常对现实造成的直接影响，至少1个是终局残留。锚点之间应互相验证或形成矛盾：

1. **日常实物：** 渔网、钥匙、旧衣服、车票、工具、饭盒等，先证明主角的现实任务存在。
2. **直接物理反应：** 绳索绷紧、船体倾斜、门被推回、地面积水、人物受伤等，证明异常不是只存在于屏幕或记录里。
3. **关系行为：** 带路人突然关灯、要求割断物品、喊出旧称呼或违背常识做选择，用动作暴露其隐瞒。
4. **终局残留：** 被割断的物件返回、旧物重新出现、新目击照片或陌生来电，把异常带回现实。
5. **辅助记录 / 记录型母题：** 照片、档案、监控、屏幕、旧录像、聊天记录等。非记录型题材原则上只用于加强已经现场看见的异常；若“记录本身就是异常母题”（如旧物录像、预言影像、名单自改写），允许作为首次异常载体，但后续必须至少有一次现实物证、行为、路线、人物或空间交叉验证，不能从头到尾只在屏幕里自证。

禁止为了满足数量机械加入日志、邮件、考勤、编号和旧档案。证据链服务于行动，不替代行动。

## 十一、评论区分裂设计

每篇结尾留至少 2 个未解释完的钩子：

1. **事实层钩子：** 围绕时间是否真实、人物是否真实、物品是否真实——让评论区争论"这件事到底有没有发生"
2. **解释层钩子：** 围绕超自然/循环/精神问题/阴谋论哪一种成立——让评论区分裂成不同派系

两个钩子均不在字幕中直接提问，交给读者自行发现矛盾。钩子检查标准：不追前作也能争论（事实层），追了前作能发现更多线索（解释层）。

## 十二、生成与发布前验收

### 12.1 每10张审核一次

1. 先生成10张，按分镜检查剧情因果、角色锁定、第一视角、异常可读性（含实体，如有）与字幕避让。
2. 不合格图单独重出；通过后再进入下一批，禁止把"以后再修"的图混入最终目录。
3. 最终发布前按排序连看一遍：静音状态下也应看懂"为什么下一张会发生"。

### 12.2 一票否决

- 不符合本集 Episode 级锁定比例，或存在黑边、白边、无依据裁切、拉伸和模糊填充。
- 主体、核心异常或关键证据因曝光/模糊而无法在手机端辨认。
- 畸形手指、错误手机屏幕、明显AI文字。
- 角色面容漂移（同一角色前后两张图脸不一样）。
- 角色服装漂移（同一角色换装或颜色变化）。
- 无解释的第三人称旁观镜头、无剧情预登记豁免的连续精致居中构图、棚拍/HDR质感。
- 前3张没有同时交代现实动机和可辨认异常证据；记录型题材允许首证据来自屏幕、旧录像、档案或照片；任何一张字幕遮挡关键线索；或字幕使用半透明气泡、黑底、居中排版、28px 小字号、三行以上长文案等违反第五章锁定规范的样式。
- 非记录型题材的核心异常长期只存在于仪器、监控、档案或聊天记录中且没有现场/现实验证；记录型题材可从屏幕/档案起手，但后续必须出现现实层交叉验证或物理后果。
- 缺少当篇所选节奏的完整标签：鼠鼠模式缺 S1~S8、Zayn 模式缺 Z1~Z8、混合模式缺任意一套；或关键规律/规则出现后没有作用于人物与现实。
- 开篇任务/进入事件没有结果；或鼠鼠、混合模式的核心人物关系没有结果，只用“未完待续”结束。
- 单篇需要读者先看前作才能看懂基本冲突。

### 12.3 制作验收分（制作完成度）

通过一票否决后，再按以下8项各打0~10分。总分为八项平均分，统一命名为 **制作完成度 / 制作验收分**，**低于8.5不得发布**；任何单项低于7.5，必须定向修复后重评。

本节只判断标题、故事、画面、字幕、连续性与合规是否达到发布质量门槛，属于**制作验收分**。它不代表抖音算法评分，不预测曝光、播放、划走率、完读、互动或涨粉。选题/分镜设计分、成片制作验收分、12.4传播预测分和发布后平台实绩必须分开记录，禁止互相替代。

| 维度 | 10分标准 |
|---|---|
| 标题抓力 | 只评分最终准备输入平台的实际标题；能快速说明身份/进入理由、直接异常和后果或同源矛盾，手机端无需展开即可理解。实际平台标题未锁定时，本项写“未提供证据”，不得借用选题卡长标题打分 |
| 前段抓力 | 前3张出现强异常，前4~6张给出可见证据或后果 |
| 剧情因果 | 所选节奏标签完整，静音连续翻页时每一张都能解释下一张的动机；混合模式两套标签均完整 |
| 随手拍真实度 | 现场光、设备质感、手抖/偏焦/遮挡等缺陷与拍摄条件因果一致；无统一压暗、棚拍、HDR和AI摆拍感 |
| 角色与场景一致性 | 核心角色面容、服装、时间、天气、空间关系连续 |
| 异常可读性与现实锚点 | 异常通过实体、行为、路线、时间、影像、物件或空间证据稳定递进；若存在实体则保持可辨认和连续；至少3个现实锚点，并形成现实交叉验证或终局残留 |
| 字幕有效性 | 42px 白字黑描边、无气泡、左对齐、最多两行；每句只承担一个功能，位置避开主体和关键线索，静默图有明确画面推论价值 |
| 原创性与账号辨识度 | 借鉴结构但不复刻表达，至少有1个属于本系列的视觉母题或证据设计 |

评分表必须保存在当篇 episode docs 中。评分人不能只写总分，低于9分的项目必须写一句扣分原因。

制作验收证据还应记录：

```text
共享风格：M00/F01/F02/F03 或 不适用
声音卡：已完成
三张校准：图号 + 版本/SHA
普通相册四问：通过
摄影红旗：无未修复的有效红旗≥3图
线索后果表：完整
```

以上属于制作门禁，不新增第四套综合分，也不修改 12.4 / 12.5。


### 12.4 传播预测卡（发布前内部预测）

> 详细执行见 [`抖音推流评分与发布后漏斗规范_V1.4.md`](抖音推流评分与发布后漏斗规范_V1.4.md)。该文件只是本规范执行细则，不建立第二权威。

制作验收通过后按以下 **9项** 各打0~10分。简单平均只用于同账号内部横向校准，不表示抖音算法权重。

| 维度 | 优先级 | 10分标准 |
|---|:---:|---|
| 实际标题承诺 | A | 最终平台短标题让陌生用户快速知道核心异常/阅读问题，并与正文一致 |
| 实际封面停留 | S | 最终封面手机端主体、异常、核心文字一眼可辨，平台裁切不损失证据 |
| 封面到图01兑现 | S | 图01继续兑现或升级封面问题，不退回无关背景、不换母题 |
| 01至05消费债 | S | 前3张完成现实动机+直接异常；前5张至少一次可见回报并形成新问题 |

| 16至结尾回报 | S | 高潮兑现前段承诺；关键证据手机端可读；完成现实残留与重读 |
| 评论诱因 | A+ | 正文自然形成至少两个竞争解释、细节回看或现实经验联想 |
| 作者链 | A+ | 单篇自治，同时让人知道主页还能稳定获得什么同类体验；不靠未完待续 |

#### 12.4.1 试运行门禁

- 强传播结构：总分 ≥9.2，且全部S ≥8.5
- 可发布：总分 ≥8.7，且全部S ≥7.5
- 有条件发布：总分8.3–8.69，或任一S为7.0–7.49
- 不建议发布：总分<8.3，或任一S<7.0

任一S<7.5时，即使平均分≥8.7，最高只能“有条件发布”；任一S<7.0直接“不建议发布”。

12.3 仍是发布质量硬门禁：12.4 高分不能放行 12.3 未通过的作品；反过来，12.3 已通过但 12.4 判为“有条件/不建议”时，应先修传播结构再决定是否按当前版本发布。\n\n这些阈值目前是**试运行门禁**：
- 累积5篇“完整九项预测 + 48h实绩”后第一次校准；
- 累积10篇后再决定是否固化；
- 未满5篇前不得把阈值表述为已被平台数据验证。

#### 12.4.2 证据纪律

1. 最终标题、封面、平台裁切、正文首图、上传顺序有关键缺证时不计算正式总分。
2. 必须记录核心承诺首次兑现图、第一次规则证明图、第一次作用于主角图、评论争论点、作者链承诺。
3. 发布后不得倒改预测分；只记录标题/封面/前5张/中段/结尾/评论/作者链的高估或低估。
4. 划走率≠01→02留存；均浏览图÷总张数≠完读率。
5. 制作完成度与传播结构分必须并列展示，禁止只写“综合9.x”。


### 12.4.3 推荐适配门禁（V2.8 新增）

九项传播结构卡继续只判断“单篇是否容易被消费”，不与推荐适配混算成一个所谓算法总分。

最终 publish 前，还必须按 `抖音推流评分与发布后漏斗规范_V1.4.md` 完成：

1. **人群匹配：** 核心 / 相邻 / 错位受众已填写，人群匹配分 ≥7；
2. **最近5篇同质化：** 最高相似度原则上 <70，且未触发“核心机制 + 中段升级 + 高潮方式”机制换皮一票否决；
3. **搜索资产：** 核心实体、核心搜索意图、长尾搜索词已填写；搜索潜力低不单独阻断发布，但必须明确其属于推荐型而非搜索资产型内容；
4. **治理风险：** 最终状态必须为 `PASS`；`REVIEW` 先人工确认，`BLOCK` 不得发布。

四把锁与最近5篇矩阵并行：前者防同系列换皮，后者防账号连续消费体验重复。

推荐适配属于发布前预测与选题治理，不得在作品发布后根据平台结果倒改当时判断。

### 12.5 发布后推流漏斗卡（平台实绩）

发布后不再给“算法分”，只记录四层实绩：

| 层级 | 核心问题 | 优先字段 |
|---|---|---|
| L1停留 | 刷到后停下来没有 | 划走率、曝光→正文/首屏字段（如有） |
| L2深度 | 停下后读了多深 | 均浏览图、平均阅读深度、真实完读/末页（如有） |
| L3动作 | 消费后愿不愿表达/传播 | 评论、分享、收藏；点赞辅助 |
| L4作者链 | 是否继续消费作者 | 主页访问、吸粉、主页转粉、旧作/系列回访 |

诊断顺序固定为 L1→L2→L3→L4。上游已失败时不优先优化下游；L1/L2已经被平台数据验证强时，不无证据重做前段。

## 十三、原创、民俗与发布合规

### 13.1 借鉴边界

- 可以学习竞品的第一人称结构、节奏和信息组织方式；不得复刻其人物关系、异常组合、标志性画面、标题措辞或连续情节。
- 正式文档统一使用"提炼鼠鼠的传播机制"，不把"复制竞品"作为对外表达或成片目标。
- 每篇至少加入一个无法用竞品标题直接替换的自有元素：系列视觉母题、地域实物证据、人物情感关系或独特规则四选一。
- 使用现成小说、影视、动漫、游戏角色或怪物设定前，必须确认授权或改为原创、IP中性的表达；不得用知名IP名称为作品导流。

### 13.2 民俗与现实地点

- 民俗内容应标注为虚构演绎，不把杜撰仪式、禁忌或伤亡事件表述为现实事实。
- 使用真实地点、民族、宗教、职业或历史事件时，避免污名化、猎奇化指控和无法证实的灾难叙述。
- 不使用真实普通人的肖像作为固定角色参考；角色参考应为本人授权素材、明确可用素材或原创生成形象。

### 13.3 发布前合规检查

- 保留"内容由AI生成"声明，并按发布时平台实际要求更新措辞。
- 检查音乐、字体、图片参考和画面内商标的可用范围；无法确认时替换为可授权或原创素材。
- 不使用血腥肢解、未成年人受害细节、自残诱导或仿真违法教程作为抓力来源。
- 标题、字幕和简介不得把虚构故事包装成已被官方证实的真实案件；可以使用伪纪录片叙事，但必须保留虚构声明。
