# StoryOS M00 R11：相邻分镜来源候选自动编制与生产准备接入（2026-10-13）

## 本轮完成的边界

R9 已将**受审且锁定的**状态增量传至 Frame Contract → Prompt Package → Image Controller → 原生 Codex Provider。R10 已能从 Markdown／JSON 提取原故事及相邻帧的 SHA 证据，但 `DRAFT_ONLY` 默认空白；即使存在草案也不能赋予 SOURCE_ATTESTED 权威。本轮仅增加“自动候选取证与生产准备挂接”，**不是自动变更创作事实，也不是自动通过 Story Review 或 Pixel Review**。

### 四槽

1. **离线取证候选。** `m00_storyboard_source_suggestions.analyze` 对故事全文、前帧、当前帧分别按中文/英文词汇采集精确原文片段和 SHA，辅助归类身份、服装、道具、地点、摄影者、光照六项。每个候选都写入 `source_suggestions.locked_quote_candidates`，标 `SOURCE_QUOTE_NOT_VERIFIED_FACT`，不得当成两帧中已证明不变的客观事实。找不到证据则填 `missing_evidence`，不能补虚构句。
2. **动作／静止的可见证据。** 只有上一帧和当前帧均有明确动作词，且指向可共享的实体线索时才产生 `observable_change_candidates`，其中 `before`、`after`、`pixel_evidence_hint` 均为原文子串，绝不凭主观补造帧。两帧明确“静止／保持不动”时才提示 `mode_hint=static`，其他不明确场景为 `UNKNOWN_NEEDS_REVIEW`；单个动作候选也不足以形成 R8 所需的正式合约。以上都是候选，模型不能自行判 PASS。
3. **正式工作流的安全挂接。** `production_prompt_materializer.prepare_queue` 只对 M00 且 canonical `story_review.review_required`、`story_review.verify` 有效、`review_authority_sha256` 存在的 Episode，调用 R10 已有草案准备函数。它在源码层预检全部帧再一次性逐个创建**仅不存在的** `DRAFT_ONLY` sidecar；已有人填写的文件绝不覆盖。不适用风格／无有效 Story Review／无法定位旧式分镜时跳过自动取证，原 Prompt/正式 Stage/Gateway 路径仍不受影响。队列返回 `m00_source_drafts`，包括草案数量和缺失项目；原有 `status/materialized/queue` 语义不变。
4. **极速测试、并发安全及治理。** 新增 Markdown/JSON 来源候选测试和实际生产队列准备入口的无模型离线验证，统一接入 `scripts/storyos_m00_fast_test.py`，并复跑 Image Controller、共享容量和自治全槽、压力测试。独立 Worktree 修改；主线原有未提交文件保留，仅成功复测后 fast-forward 推送主分支。Worktree 清理只允许经过 72h、合并祖先、无脏文件／活动任务的退役计划执行。

## 精确权限边界

`source_suggestions` 中的原文引用**不自动复制到 `delta.locked` 或 `delta.observable_changes`**，因为引用并不能证明人物真的相同、摄影者机位可达、前后动作物理合理。正式 `SOURCE_ATTESTED` 仍需要编辑填写明确合同、逐字来源约束、Story Review Authority SHA、人工确认。R9 Provider 可用状态不代表某个旧 Episode 已获得生成权威；新草案和旧实图不能用于模拟正式 MySQL Attempt、Pixel PASS 或消耗 Provider 权限。

## 只读／显式草案操作

```powershell
python scripts/storyos_m00_storyboard_delta_drafts_r10.py "episodes/作品目录"
python scripts/storyos_m00_storyboard_delta_drafts_r10.py "episodes/作品目录" --apply
python scripts/storyos_m00_fast_test.py
python scripts/storyos_autonomy_fast_test.py --slot all
python scripts/storyos_autonomy_fast_test.py --slot all --stress
```

第一条仅返回每帧 `quoted_lock_categories`、`observable_change_candidates`、`mode_hint`、`missing_evidence` 等摘要；第二条仅补齐不存在的待审文件。正式生产准备入口在有效 M00 Story Review 下也会自动执行此草案创建。整个过程**不调用原生 Codex 模型或任何生图 Provider**，只是让用户已登录的原生 Codex 生产链在完成真正权限审核后使用更充分的来源资料。

历史 R8 C02-T01 的真实图质量结论仍为 `UNCERTAIN_NEEDS_FULL_REVIEW`，不因本轮代码提交改变。
