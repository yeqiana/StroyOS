# StoryOS M00 风格参考图类型透传 R4（2026-10-13）

## 实际缺陷

原生 Codex 的图片 Payload 传输提示词此前将每张附件一律描述成 identity/continuity reference。用户的风格样张（包括带系统 UI 的手机截图）不能被当作人物、动作、服装、场景或剧情权威。

## 修复

1. 从图片调度器的引用声明，经 image_worker_pool 按序保留可选 kind / role。
2. image_payload_request 的 canonical references 保留 kind / role，纳入现有 fingerprint。非法类型 / 多行 role 拒绝，旧无类型引用仍兼容。
3. 原生 Codex transport 为每张附件写明限定用途：identity 为人物连续性；prop / location 只能用于 Story 确认的道具与地点；capture_style 只借鉴成像、摄影物理、曝光，不借鉴人物、动作、环境、服装、截图 UI 或时间戳。
4. Reference 不授予 Stage/Visual Lock PASS。正式图片仍走 Image Gateway、共享容量、Attempt Authority、Provider 回执与实际像素审核。
5. 不把参考图中的户外、救援、背包、多人站位等作为默认 Story 或动作。
